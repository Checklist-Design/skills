# Accordion — Design system

An accordion is a vertically stacked list of items that reveal or hide associated content sections when clicked. They help organize information hierarchically and saves screen space by showing only relevant content.

Source: https://www.checklist.design/design-system/accordion

## Items

### Header
The clickable area that triggers expanding and collapsing and has a title

_Tip: The header text should clearly convey the content that is inside_

### Expand/collapse icon
Visual indicator of the current state — typically a plus/minus, or a caret/chevron that rotates between states

### Content area
The content that shows or hides when toggled, containing detailed information associated with the header

_Tip: While headers should be text only, content can be anything that is suited to help answer or elaborate on the header (text, image, video, etc)_

### States
Default (collapsed), expanded, hover, focused, and disabled

### Expanding logic
Decide if users can open multiple sections at once, or one at a time

_Tip: Can be determined by whether you think information from other items are related and should be seen together_
