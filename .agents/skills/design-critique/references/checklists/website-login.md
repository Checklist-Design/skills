# Login — Website

A login page is a critical component of many web applications and websites, serving as the gateway for users to access personalized features, secure content, and their own data.

Source: https://www.checklist.design/website/login

## Items

### Logo
Either your complete logo or a symbol mark

### Title
Tell the user this is where they login

### Account identification
A unique identifier for the user

_Tip: Consider multiple identifiers to login with e.g. username, or email address, or phone number_

### Password
A secure, private code that allows access to their account

_Tip: Create the ability to make the password visible_

### Link to reset password
A user may forget their unique code - let them change it!

_Tip: Position this link close to your password input field_

### Link to sign up
A user may not have an account and landed on this page anyway

### Login via third party
Turn text fields into one click by allowing users to connect via a third party e.g. Google, Apple, Facebook, Twitter

### Testimonial
Reinforcing the brand and product never goes out of style

### Blog post
An opportunity to show off content relevant to the user

### New feature
The perfect way to build excitement for something new right before a user is about to log in and see it!
