# Maintenance — Web app

A screen shown when the application is temporarily unavailable due to scheduled maintenance or an unexpected outage.

Source: https://www.checklist.design/web-app/maintenance

## Items

### Clear status message
A plain-language explanation that the product is currently unavailable and why

_Tip: Scheduled maintenance and unexpected outages call for different messaging, since users respond very differently to each, and conflating them feels evasive_

### Estimated return time
When the product is expected to be back online, as specifically as possible

_Tip: Vague messages like 'back soon' frustrate users, since even a rough estimate like 'within 2 hours' is far more reassuring_

### Status page link
A link to a live status page where users can monitor progress and see real-time updates

_Tip: A status page hosted on a separate domain remains accessible even when your main infrastructure is down_

### Contact or support link
A way to reach support for urgent issues that cannot wait for the maintenance window to end

### Brand consistency
A maintenance page styled consistently with the product, even if the content is minimal

_Tip: A well-designed maintenance page communicates professionalism and reduces user anxiety_
