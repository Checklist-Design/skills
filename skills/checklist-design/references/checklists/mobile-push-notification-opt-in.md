# Push Notification Opt-in — Mobile app

The custom screen shown before the system notification prompt to persuade a user to accept push notifications before they see the binary system dialog.

Source: https://www.checklist.design/mobile/push-notification-opt-in

## Items

### Value proposition
A specific explanation of what the notifications will contain and why they are worth receiving

### Notification preview
A realistic visual mock of what a notification from this app looks like (title, body, and app icon)

_Tip: A genuine-looking sample (rather than a generic illustration) significantly helps_

### Opt-in timing
The point in the flow at which the opt-in is presented, after the user has experienced enough value to understand what they'd be opting into

_Tip: Presenting a push opt-in before the user has completed any meaningful action is the fastest way to get a denial_

### Decline path
A clear dismiss option that does not penalise the user or block progress

### Re-engagement path
For users who decline, a way to revisit the opt-in later (typically surfaced in settings)

### One screen, one ask
A single, focused screen making one case for one permission
